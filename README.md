# Батлер Сервис

Рабочее место батлерской службы отеля: учёт рабочего времени (График, Табель, банк часов,
переработки), шахматка гостей и броней, ночной отчёт, электрокары, документы и уведомления.
Расчёт времени ведёт детерминированный движок v7.1.

## Быстрый старт

```bash
cd butler-service
docker compose up -d --build   # приложение, воркер и PostgreSQL
```

Откройте http://127.0.0.1:8000, вход `admin` / `demo1234`. При первом запуске база заполняется
демо-данными. Сброс: `docker compose down -v`. Демо-базы прежних версий не обновляются —
пересоздайте.

## Проверки

```bash
uv sync && source .venv/bin/activate
docker compose up -d db
python -m pytest tests/ -q       # весь набор
python -m ruff check .
npm install && npm run lint
npx playwright test              # сценарии в браузере
```

Остальные команды и правила — [документ 4](docs/04-razrabotka.md).
