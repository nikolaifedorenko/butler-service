# Изменения 12.10.2026 — Табель/График: батч T1+T3+T4 (норматив «График = 4 слоя»)

Первый PR с кодом приложения после согласования норматива 12.10.2026
(`docs/REVIEW-GRAFIK-4-SLOYA-2026-10-12.md`). Реализованы задачи **T1**, **T3**, **T4**
по подтверждённым решениям владельца (Q3, Q4, Q5, Q8, Q9). T5 (навигация «График = 4 слоя»)
— следующий отдельный PR. Версия статики: **2026-10-12c**.

## T1 — «код в табеле» у смены: только справочник CFG-DAY-CODES или пусто

Дефект: редактор смены отправлял одно поле `short_code`, а API писал его значение в ОБА
столбца — `display_code` и `tzh_code`. В поле кода Табеля оказывалась подпись сетки
(«08-20»), которой нет в справочнике: health-панель выдавала 6 ошибок **APP-SHIFT-CODE**,
а ночные/суточные смены переставали заполнять Табель из циклов (`_anchor_value` требует
код, несущий часы). Модель не меняется (ответ на Q9): код Табеля по-прежнему жёстко
определяет стандартное окно, эти же часы попадают в График первоначальными сменами.

- **Редактор смены** (`static/js/app.js`): два независимых поля — «Код в сетке (подпись
  ячейки)» (`#sh-short`, свободный текст, только отображение) и «Код в табеле
  (CFG-DAY-CODES)» (`#sh-tzh`, **выбор из справочника** или «— не задан —»). Подсказка
  `#sh-tzh-hint` объясняет последствия: код несёт часы → стандартное окно из CFG-WINDOWS;
  пусто → смена не участвует в автозаполнении (например, «отпросился»). Прежнее значение
  не из справочника показывается пунктом «⚠ … (будет очищено)».
- **API** (`app/api/employees.py`): `_split_codes()` разводит поля и валидирует `tzh_code`
  по действующей версии справочников — чужой код отклоняется **422** с перечислением
  допустимых; PUT без поля `tzh_code` его не обнуляет. Новый роут
  `GET /api/shift-types/tabel-codes` — словарь кодов для редактора (code/title/carries_hours).
- **Миграция** (`app/migrations.py::migrate_shift_tabel_codes`, вызывается из
  `app/main.py`): у смен с `tzh_code` не из словаря действующей версии поле очищается
  (идемпотентно; `display_code` и ревизии не трогаются). Пустое поле — честное состояние,
  владелец ставит код через исправленный редактор.
- **Настройки → Смены** (`static/js/section_settings.js`): панель «Связь словарей» объясняет
  правило поля; у битых ссылок появилась кнопка «Исправить» (открывает тот же редактор).
- **Health** (`app/api/engine_settings_api.py`): текст APP-SHIFT-CODE дополнен подсказкой,
  что допустимы только коды справочника или пустое значение.

## T3 — «Сбросить» в Табеле (Q5)

Табель — первичный документ: заполняется из циклов сотрудника, а ручная правка ячейки
(`source="manual"`) автозаполнением больше не перезаписывается. «Сбросить» возвращает период к автозаполнению.

- **`POST /api/tabel/reset`** (`app/api/tabel_api.py`): удаляет РУЧНЫЕ строки периода
  (месяц либо половина — `period_granularity`), заново запускает `fill_timesheet_from_cycles`
  и `rebuild_generated_schedule` (График перегенерируется из Табеля, 16.3). Границы как у
  «Заполнить из циклов»: закрытые периоды пропускаются (`locked_skipped`,
  RUL-CLOSED-PERIOD-IMMUTABLE), дни вне трудоустройства не заполняются
  (RUL-EMPLOYMENT-PERIOD); дни, которые цикл не покрыл, возвращаются в `uncovered` —
  иначе расчёт УТ не запустится (RUL-TIMESHEET-COVERS-PERIOD). Пересчёт часов не
  запускается (16.1 п.2). Ответ: `cleared/cells/written/skipped/warnings/uncovered/
  uncovered_total/locked_skipped/manual_shifts_dropped`. Действие аудируется
  (`tabel_reset` — новый ACTION_TITLE «Сброс Табеля»).
- **UI** (`static/js/section_v4.js`): кнопка «Сбросить» в панели Табеля (рядом с «Заполнить
  из циклов»), модалка `tabelResetModal`: объяснение, счётчик ручных ячеек, выбор
  «всем / одному сотруднику», двухшаговое подтверждение; в тосте — итоги
  («очищено ручных ячеек: N, заполнено из циклов: M», пропущенные закрытые и непокрытые дни).

## T4 — «Отпросился (выходной за часы)»: одна сущность, два входа, заявления из своего слоя (Q3, Q4, Q8)

- **Словарь** (`app/seed.py`): один вид `TIMEOFF_HOURS` «Отпросился (выходной за часы)»
  (подпись «ОТПР», документ `day_off_hours`, кода Табеля нет — это данные Графика).
  Дубль `AWAY_HOURS` удалён из сида.
- **Миграция** (`migrate_timeoff_entity`): старым базам записи отсутствий `AWAY_HOURS`
  переносятся на объединённый вид, дубль архивируется (прошлые ячейки и заявления остаются
  читаемыми); название приводится к нормативному, если его не меняли руками. Идемпотентно.
- **Две точки ввода** (ячейка Графика, `static/js/app.js`): «Отпросить на интервал»
  (`#cell-abs-save`) и «На всю смену» (`#cell-abs-shift`, границы берутся из смены дня) —
  доступны для любого вида «за счёт часов». Назначение **информационное** (Q8): план, часы
  и банк не меняются; неотработанные часы окна уходят в недостачу дня, которую при закрытии
  гасит банк 1:1 (EX-29); в Табеле остаётся явка.
- **Слойность (Q4)**: из Графика назначаются только виды без кода Табеля — кнопка панели
  переименована в «Отпросить (выходной за часы)», `openRangeModal('schedule')` показывает
  ровно этот вид; отпуск/ДО/Б/ОВ/НН — коды первичного документа, ставятся из Табеля
  (`openRangeModal('tabel')`, кнопка «Назначить отсутствие» в панели Табеля).
- **Заявления из своего слоя**: `GET /api/schedule/absence-period` отдаёт `source`
  (`tabel_code` / `schedule_absence`), `whole_shift` и `doc_type` — вид заявления выбирает
  сервер (`doc_type_of_absence`): вся смена → «выходной за ранее отработанные часы»
  (`day_off_hours`), интервал → «об отсутствии на рабочем месте» (`time_off_request`).
  В ячейке Табеля для кодов отсутствия появился блок «Заявление по коду Табеля»
  (печать / DOCX / PDF — период находится целиком, даже через границы месяца).
  Кнопка не того слоя не печатает чужой документ, а объясняет, куда идти
  (`statementLayerOk`). Мёртвая таблица `DOC_TYPE_BY_SHIFT_CODE` удалена из
  `app/doc_render.py` (вид заявления теперь определяет сервер).

## Попутно в редакторе ячейки Табеля

- Код без часов сохраняется с планом 0: скрытое поле часов больше не отправляет прежнее
  значение (сервер честно возвращал 422 CHK-PLAN-CONSISTENT без подсказки).
- При переключении на код с часами и пустом/нулевом плане подставляется первое окно кода
  из CFG-WINDOWS (например, «Я 8»).
