## 1. Кары: два «взять» одного кара (CONC-01)

* `take_car` захватывает кар условным UPDATE (`WHERE status = <прочитанный>`). Второй из
  одновременных запросов получает 409 «Кар только что взял другой сотрудник — обновите экран»,
  в истории остаётся одна запись `take`.
* Правило «один сотрудник — один кар» держит база: частичный unique-индекс
  `ux_cars_holder_user_id` (`holder_user_id IS NOT NULL`), ревизия `0004`. Нарушение при
  параллельной выдаче или передаче — тоже 409.
* Если в базе уже есть человек с двумя карами, индекс не создаётся (данные не трогаем), а в лог
  идёт предупреждение с SQL для ручного создания. Боевой базы нет (В-1), на новой базе этот
  случай не возникает.

## 2. Отправка недостатков службам (CONC-02; AUTHZ-08, В-5)

* Новое право `night.dispatch` «Отправка недостатков службам». По умолчанию оно есть у всех
  ролей и снимается в «Правах доступа». Маршрут требует и его, и `night.view`. Без права кнопки
  отправки неактивны, рядом подсказка.
* Отправка идёт под межпроцессным замком `try_lock("night-dispatch")`. Вторая одновременная
  попытка (двойной клик, повтор после таймаута, второй супервайзер) получает 409 и ничего не
  отправляет. После первой отправки повтор не найдёт неотправленного: пометки коммитятся до
  снятия замка.
* **Не сделано:** outbox с фоновым отправщиком. Если процесс упадёт между отправкой и commit,
  следующая отправка повторит эти сообщения (`shortcut:` в `night_notify.py`).

## 3. Настройки расчёта: две вкладки (CONC-03)

`GET /api/engine-settings` отдаёт `latest_id`. Оба редактора («Настройки → Расчёт» и старый
экран справочников Табеля) присылают его как `base_version_id`. Если с тех пор вышла новая
версия, сервер отвечает 409 «обновите страницу». Если поля нет, проверка не выполняется: так
продолжат работать скрипты.

## 4. Загрузки не держат event loop воркера (CONC-04)

* `upload_template`, `add_item_photo`, `report_car_check` и `car_return` объявлены через `def`,
  а не `async def`. `read_upload_streaming` стал синхронным и читает `UploadFile.file`.
  FastAPI выполняет такие обработчики в пуле потоков, поэтому загрузка фото больше не
  останавливает соседние запросы.
* Страж `test_conc04_route_handlers_are_sync`: под `@router` нет ни одного `async def`.

## 5. Таймауты долгих операций (UI-03)

* `timeout: 300000` получили отправка службам, повтор доставки, проверка Telegram, тестовое
  письмо, закрытие и пересчёт периода. PDF и XLSX скачиваются через `fetch` без таймаута, их
  это ограничение не касалось.
* Если изменяющий запрос оборвался по таймауту, клиент пишет: «действие могло выполниться:
  обновите экран, прежде чем повторять».

## 6. Один часовой пояс (HARD-01, В-10)

* Версия настроек с `tz`, отличным от `APP_TZ`, отклоняется с ошибкой 422. Пустой `tz`
  заполняется значением `APP_TZ`.
* В редакторе «Расчёт» пояс только для чтения, значение приходит с сервера (`/api/health`).
  Подпись пояса на экране каров тоже берётся с сервера; раньше там была константа
  `'Europe/Moscow'` в JS.
* Окно ночной смены 20:00–08:00 не менялось (решение владельца).

## 7. Архив ночи (PERF-01)

вместо 774. Бюджет в `test_query_budget.py` — не больше 10.
