# Изменения 20.10.2026 — долг №3 закрыт: «сегодня» только из `core/time` (DoD TZ/now)

Решение владельца: вариант A (перевод на `local_date()` + граничные тесты +
механический страж). Последний незакрытый пункт DoD «TZ/now — только
`core/time.py`» из §17 EXECUTION-SPEC-v2.

## 1. Проблема

9 вызовов читали СИСТЕМНУЮ дату/время сервера вместо даты объекта (APP_TZ):
`tabel_api._code_titles`, `engine_settings_api` ×4 (действующая версия
справочников, день модификатора по умолчанию, гранулярность, health-обзор),
`timesheet/bootstrap` (диапазон посева Табеля), `engine_common.day_code_colors`,
`bootstrap/migrations` (миграция словаря смен), `bootstrap/seed` (now для портов).

При TZ сервера ≠ APP_TZ (например, контейнер UTC при объекте в Москве) в окне
21:00–24:00 UTC «сегодня» расходилось с локальной датой объекта на сутки —
экраны «Расчёт»/«Настройки» выбирали вчерашнюю версию справочников CFG-* ровно
в ночную смену. Баг был латентным (прод-стек задаёт TZ=Europe/Moscow), но
нарушал принцип единственного источника времени и DoD.

## 2. Что сделано

* Все 9 точек → `app.core.time.local_date()` (дата объекта); `seed.py` →
  `now_utc()` (канонический composition-параметр из `timesheet.application`).
* `now_utc()` остаётся единственной читкой системного времени в модулях —
  это разрешено спекой (§5.1/F-15: `now` снимается в composition-точке и
  передаётся параметром; без ClockPort). `main.health` показывает серверное
  время намеренно (диагностика).
* **AST-страж** (`tests/test_modules_architecture.py::
  test_no_system_time_reads_in_modules`, ×9 модулей): любое `date.today()`/
  `datetime.now()` в `app/modules/**` падает тестом; allowlist — только
  `engine_common.py: now`. Долг нельзя вернуть молча.
* **Граничные тесты** (`tests/test_tz_local_date.py`): freezegun 22:30 UTC =
  01:30 следующих суток в Москве: (1) инвариант `local_date() ≠ серверное
  today()`; (2) `day_code_colors()` выбирает версию справочников с
  `valid_from` = дата ОБЪЕКТА (до фикса в этом окне побеждала вчерашняя).
  HTTP-вариант теста не используется сознательно: freezegun подменяет
  `dt.date`, и FastAPI/pydantic ломаются на аннотации `on: Optional[dt.date]`
  (известное ограничение; страж AST покрывает вызовы вместо HTTP-теста).
