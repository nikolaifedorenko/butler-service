  эталонных тестов notify (C3) на все 9 модулей + core:
  структура (5 слоёв с `__init__` у каждого модуля), R1-чистота домена
  (stdlib + свой домен + core.errors; без I/O и системного времени), чистота

  публичная граница notify (R4, `__all__` = поверхность бывшей app/notify).
* Задокументированные исключения (данные тестов, не ослабление закона):
  изначальная архитектура движка — `factory.py → application.context`,
  `sql_bank/sql_closings → application.months`, `sql_closings → interface.
  serialize/deserialize` (перенесены «как есть» §4; кандидаты на продуктовый
  батч «порты/DTO»); R6-allowlist — CHANGES C4 §2.
* `tests/test_notify_module.py` удалён — его проверки поглощены общим тестом.
* Законы движка v7.1 (чистота домена, независимость конвейеров, размер файлов,
  EX-каталог) остались в `tests/engine/test_architecture.py` — они строже общих.
