# Архив

Материалы, которые уже реализованы и не участвуют в сборке и CI. Хранятся для истории решений;
пути внутри них описывают структуру на свою дату. Проверка ссылок (`tools/doc_links.py`) их
не проверяет.

* `prototypes/` — кликабельные прототипы ночного отчёта v2 и центра настроек (19.10.2026) со
  смоук-скриптами; оба реализованы в приложении. Перенесены сюда 22.10.2026 (аудит, DEAD-03).
* `changes/` — подробные описания батчей изменений 18–22.10.2026 (`CHANGES-<дата>-<тема>.md`).
  Сводка по датам и PR — [`CHANGELOG.md`](../../CHANGELOG.md) в корне; новые записи идут туда.
* `EXECUTION-SPEC-v2.md` — спецификация модульной перестройки (этапы A–C, 20.10.2026),
  выполнена полностью. Её правила R1–R6 действуют: они закреплены в `ARCHITECTURE.md`, ADR-0010
  и тестах архитектуры.
