# Архив

Материалы, которые уже реализованы и не участвуют в сборке и CI. Хранятся для истории решений;
пути внутри них описывают структуру на свою дату. Проверка ссылок (`tools/doc_links.py`) их
не проверяет.

* `prototypes/` — кликабельные прототипы ночного отчёта v2 и центра настроек (19.10.2026) со
  смоук-скриптами; оба реализованы в приложении. Перенесены сюда 22.10.2026 (аудит, DEAD-03).
* `changes/` — подробные описания батчей изменений 18–22.10.2026 (`CHANGES-<дата>-<тема>.md`).
  Сводка по датам и PR — [`CHANGELOG.md`](../../CHANGELOG.md) в корне; новые записи идут туда.
* `EXECUTION-SPEC-v2.md` — спецификация модульной перестройки (этапы A–C, 20.10.2026),
  выполнена полностью. Её правила R1–R6 действуют: они закреплены в `ARCHITECTURE.md`, ADR-0010
  и тестах архитектуры.
* `specs-stays/` — исходные дизайн-документы «Шахматки», части 1–4 с дополнением и роадмап
  (23.10–02.11.2026, все реализованы: PR #121–#129). Консолидированная спецификация модуля —
  [`docs/specs/stays/spec.md`](../specs/stays/spec.md), действующие решения владельца —
  [`docs/specs/stays/decisions.md`](../specs/stays/decisions.md). Перенесены сюда 03.11.2026
  из `docs/superpowers/specs/`.
* `plans-stays/` — планы реализации частей «Шахматки» (выполнены). Перенесены 03.11.2026 из
  `docs/superpowers/plans/`.
* `proposals/` — реализованные предложения: `PROPOSAL-NIGHT-REPORT-V2.md` (ночной отчёт v2 —
  спецификация [`docs/specs/night/spec.md`](../specs/night/spec.md)) и
  `PROPOSAL-SETTINGS-IA-2026-10-19.md` (информационная архитектура Настроек — реализована,
  SPEC.md §8). Перенесены 03.11.2026 из корня `docs/`.
* `overtime_spec_v7_1_final.md` — копия спецификации расчётного ядра v7.1 без правок
  (действующая редакция — [`docs/specs/timesheet/spec.md`](../specs/timesheet/spec.md)).
