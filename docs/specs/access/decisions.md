# Решения — Вход и права доступа (access)

**Статус:** реестр действующих решений
**Редакция:** 1.0 от 03.11.2026

Только действующие решения; отменённые не хранятся. Нумерация собственная (AC-#); из
кода не цитируется. Архитектурные решения — ADR-0003/0004/0005/0007/0011/0012 (индекс в
[`../platform/decisions.md`](../platform/decisions.md)); сквозные P1/P5/P9 — там же.

| ID | Дата | Решение | Обоснование | Где реализовано |
|----|------|---------|-------------|-----------------|
| AC1 | 22.10.2026 | Роли как данные: ранги + гранты, права модулей — из манифестов; builtin-роли не удаляются | Единая модель прав вместо хардкода (фаза 5 аудита) | `app/core/identity.py`, ADR-0011/0012 |
| AC2 | 15.10.2026 | Имперсонация включена по умолчанию (`employees.impersonate`) | Поддержка; усиление «подтверждение паролем» предложено, не принято | SECURITY.md, P1 platform |
| AC3 | 25.10.2026 | Начальный пароль не возвращается сервером и не показывается; сгенерированный — один раз, с «Скопировать» | Пароль не светится в ответах и тостах | батч 6115788 (CHANGELOG 25.10.2026) |
| AC4 | 25.10.2026 | Сессия принимается только с типом токена `session`; выкатка один раз разлогинит всех — принято | Защита от подмены типа токена | `app/core/auth.py` (тип токена), P9 platform |
| AC5 | 21.10.2026 | Увольнение закрывает сессии сотрудника | Уволенный не остаётся в системе | батч 418d62f |
