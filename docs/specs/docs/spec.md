# Модуль «Заявления и бланки» (docs) — спецификация

**Статус:** норматив
**Редакция:** 1.0 от 03.11.2026 (консолидация действующего поведения по коду HEAD a3304a9)

## 1. Назначение

Печатные формы и кадровые документы (.docx) по корпоративным шаблонам: заявления
(в том числе «Отпросился (выходной за часы)» из Графика), сетки и бланки. Порядок в
меню — 80 (манифест, ADR-0012).

## 2. Правила

* **Шаблоны** — корпоративные .docx с плейсхолдерами `{field}`; загружаются один раз
  (Настройки → «Шаблоны документов компании») и хранятся в папке `templates/` рядом с
  проектом.
* При рендере **сохраняются шрифты, стили, колонтитулы и подложка** шаблона: текст
  подставляется в существующие run'ы параграфов (включая таблицы и колонтитулы) —
  форматирование документа не меняется.
* Плейсхолдеры, разбитые Word на несколько run («{full_» + «name}»), склеиваются.
* Документы отдаются строго OOXML (`.docx`) — без наследия `.doc`.
* PDF — без LibreOffice (генерация на стороне приложения, батч 21.10.2026).

## 3. Состав

`application/doc_templates.py` — справочник шаблонов и их загрузка;
`application/doc_render.py` — рендер подстановкой; `application/grid_docx.py` — сетки
(печатные формы расписаний/таблиц). Роутер — `interface/docs_api.py`.

## 4. Права

Просмотр и печать — по манифесту модуля (`app/modules/docs/manifest.py`); загрузка
шаблонов — экран Настроек (`settings.edit`).

## 5. Тесты

Юнит-тесты рендера (склеенные run'ы, таблицы, колонтитулы), смоук печати из Графика.
