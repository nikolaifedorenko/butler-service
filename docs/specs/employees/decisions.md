# Решения — Сотрудники (employees)

**Статус:** реестр действующих решений
**Редакция:** 1.0 от 03.11.2026

Только действующие решения; отменённые не хранятся. Нумерация собственная (E-#); из кода
не цитируется. Смежные: Н1–Н7 (настройки, приложение А.12 timesheet), AC5 (сессии при
увольнении), R23/R35/R38 (timesheet).

| ID | Дата | Решение | Обоснование | Где реализовано |
|----|------|---------|-------------|-----------------|
| E1 | 18.10.2026 | Значение рабочего дня сотрудника — ключ CFG-WINDOWS в шаблоне блока (`pattern_json → "value"`), fallback — значение блока; цикл отвечает только «рабочий ли день» | Табель первичен, График — зеркало (Н1 timesheet) | `BlockAssignment`, карточка сотрудника |
| E2 | ≤18.10.2026 | Закрепление электрокара — в карточке сотрудника (супервайзер и выше), один сотрудник — один кар | Закрепление — атрибут сотрудника | `../cars/decisions.md` C2 |
| E3 | 21.10.2026 | Увольнение: сессии закрываются, период трудоустройства завершается; повторный приём — новый период | Цепочка периодов ядра начинается с `Employment.start` | `application/lifecycle.py` |
| E4 | ≤20.10.2026 | Данные сотрудников другим модулям — только через публичный каталог | Граница модулей (R3, ADR-0010/0012) | `application/catalog.py` |
| E5 | ≤20.10.2026 | Перевод между группами/блоками внутри периода допустим — группа разрешается подневно | RUL-GROUP-PER-DAY (timesheet) | `application/lifecycle.py` |
