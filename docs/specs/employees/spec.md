# Модуль «Сотрудники» (employees) — спецификация

**Статус:** норматив
**Редакция:** 1.0 от 03.11.2026 (консолидация действующего поведения по коду HEAD a3304a9)

## 1. Назначение

Кадровое ядро приложения: сотрудники, трудоустройства (периоды), жизненный цикл
(перевод, смена блока графика, увольнение, повторный приём), карточка сотрудника
(закрепление кара, значение рабочего дня, банк часов). Порядок в меню — 20 (манифест,
ADR-0012).

## 2. Правила

* **Роутер тонкий** (ADR-0006): HTTP — права, DTO, статусы; бизнес-правила — в
  `application/lifecycle.py` и `application/employment.py`; ошибки — исключения
  `core.errors` (main.py маппит их в статусы); аудит и commit — часть use-case'а.
* **Период трудоустройства** — источник для эффективного периода расчётного ядра
  (R23/R35 timesheet) и доски «Отметки» (R38); интервалы `employment_periods`.
* **Публичный каталог** (`application/catalog.py`: `Employee` и др.) — единственная
  поверхность данных для других модулей (stays, night); чужие адаптеры приватны (R3).
* **Значение рабочего дня сотрудника** (ключ CFG-WINDOWS, «Я 10,75») хранится в шаблоне
  блока (`BlockAssignment.pattern_json → "value"`); выбирается в карточке при приёме и
  переводе в блок, fallback — значение блока в настройках объекта (Н1 timesheet).
* **Закрепление кара** — в карточке сотрудника, право супервайзера и выше; один
  сотрудник — один закреплённый кар (C2 cars).
* **Увольнение** закрывает сессии (AC5) и завершает период трудоустройства; повторный
  приём — новый период; цепочка периодов расчётного ядра начинается периодом, содержащим
  `Employment.start`.
* Перевод между группами/блоками внутри периода допустим — группа сотрудника
  разрешается подневно (RUL-GROUP-PER-DAY timesheet).

## 3. Права

| Право | Что даёт |
|---|---|
| `employees.view` | список и карточки сотрудников |
| `employees.edit` | приём, перевод, увольнение, карточка (супервайзер и выше) |
| `employees.bank` | просмотр банка часов сотрудника |
| `employees.impersonate` | имперсонация (администратор) |

## 4. Тесты

Юнит-тесты жизненного цикла и периодов, матрица прав, интеграция с timesheet
(эффективный период, доска) и stays (каталог батлеров).
