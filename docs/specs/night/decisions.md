# Решения — Ночной отчёт (night)

**Статус:** реестр действующих решений
**Редакция:** 1.0 от 03.11.2026

Только действующие решения; отменённые не хранятся (история — CHANGELOG и архивное
предложение PROPOSAL-NIGHT-REPORT-V2). Нумерация собственная (N-#); из кода не цитируется.

| ID | Дата | Решение | Обоснование | Где реализовано |
|----|------|---------|-------------|-----------------|
| N1 | 19.10.2026 | Отчёт создаётся автоматически на каждую смену 20:00; пропущенная (сервер выключен) — досоздаётся «задним числом» при старте | Ночная смена не должна остаться без отчёта | `application/night.py`, `bootstrap/night_sync.py` |
| N2 | 19.10.2026 | Области и пункты чек-листов — снимок на момент создания отчёта | Правки справочников не ломают открытые и закрытые отчёты | `application/night.py` |
| N3 | 19.10.2026 | Закрепление области за батлером рекомендательное: перехват разрешён, с предупреждением и записью в историю | Реальная ночная смена гибче расписания | `application/night.py` |
| N4 | 20.10.2026 | Секцию закрывает кто угодно; переоткрыть может только закрывший или супервайзер | Баланс скорости и контроля (осознанно оставлено как есть — аудит) | `take_section`/`close_section`, ТЗ |
| N5 | 20.10.2026 | Переоткрытый отчёт (`reopened_at`) закрывается только вручную; фоновая синхронизация его не трогает | Менеджер исправляет отметки без гонки с автозакрытием | `application/night.py` (осознанно оставлено — аудит) |
| N6 | 19.10.2026 | Обслуживание (досоздание, автозакрытие) — при старте и фоновым потоком, не в GET-запросах раздела | Чтение не имеет побочных эффектов | `bootstrap/night_sync.py` |
| N7 | 19.10.2026 | Автозакрытие 08:00: все области закрыты → «полный», иначе «неполный»; закрытый отчёт только для чтения | Итог смены фиксируется сам | `application/night.py` |
