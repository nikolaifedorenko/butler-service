## Решения прикладного слоя настроек, 18.10.2026 (приложение А.12 спеки)

Нормы расчётного ядра не меняют; касаются инструментов ввода Табеля и Графика (1.3, 16).

| ID | Решение | Где реализовано |
|----|---------|-----------------|
| Н1 | Табель первичен, График — зеркало: заполнение из циклов берёт код и план из значения рабочего дня сотрудника (ключ CFG-WINDOWS в шаблоне блока); цикл отвечает только «рабочий ли день» | А.12 п.1; `settings_calendar`, блоки/циклы |
| Н2 | Справочники независимы: связка «смена → код Табеля» и `deduct_from_bank` удалены; словарь смен — только добавляемые смены и системное отсутствие «Отпросился (выходной за часы)» | А.12 п.2 |
| Н3 | График по умолчанию — копия смен Табеля с цветом кода; ручная смена Графика часы Табеля не меняет (RUL-TIMESHEET-WINS — явное правило) | А.12 п.3 |
| Н4 | «Отпросился (выходной за часы)»: две точки ввода (интервал / всё окно); шаблон заявления выбирается в диалоге и первее правила по точке входа; печать — из Графика | А.12 п.4; `schedule_absences.doc_type` |
| Н5 | Базовый цикл объекта — только цикл смен и опорная дата; «Смена 2 в противофазе» — системная константа | А.12 п.5 |
| Н6 | Список кодов Табеля компактен: флаги расчёта, режим отметок и заявление — только в карточке кода | А.12 п.6 |
| Н7 | Health-панель: сверки APP-SHIFT-CODE и APP-CODE-NO-SHIFT удалены, добавлена APP-EMP-NO-VALUE; предохранитель публикации «код стоит в Табеле» сохранён | А.12 п.7 |
