# Решения — Электрокары (cars)

**Статус:** реестр действующих решений
**Редакция:** 1.0 от 03.11.2026

Только действующие решения; отменённые не хранятся (история — CHANGELOG). Нумерация
собственная (C-#); из кода не цитируется.

| ID | Дата | Решение | Обоснование | Где реализовано |
|----|------|---------|-------------|-----------------|
| C1 | ≤18.10.2026 | «На зарядке» — отдельный статус, кар в нём можно взять | Кар может понадобиться владельцу до конца зарядки | `application/cars.py` |
| C2 | ≤18.10.2026 | Один сотрудник — один закреплённый кар; закрепление рекомендательное и ставится в карточке сотрудника (супервайзер и выше), в каре только отображается | Закрепление — атрибут сотрудника, не кара | `application/cars.py`, `employees` |
| C3 | ≤18.10.2026 | Передача внутреннего сотрудника — с его согласия: кар остаётся занятым, меняется держатель, возврат отмечает новый держатель | Непрерывность ответственности | `application/cars.py` |
| C4 | ≤18.10.2026 | Внешние сотрудники (без учётной записи) — по ФИО; возврат отмечает любой | Гостевые кары без аккаунтов | `application/cars.py` |
| C5 | ≤18.10.2026 | Замечания при возврате → автоматически «на обслуживании»; снимает только менеджер/администратор | Неисправный кар не уходит следующему | `application/cars.py` |
