# Решения — Настройки (settings)

**Статус:** реестр действующих решений
**Редакция:** 1.0 от 03.11.2026

Только действующие решения; отменённые не хранятся. Нумерация собственная (ST-#); из кода
не цитируется. Смежные: Н1–Н7 (прикладной слой настроек Табеля/Графика —
[`../timesheet/decisions.md`](../timesheet/decisions.md)), P13 (bump_version).

| ID | Дата | Решение | Обоснование | Где реализовано |
|----|------|---------|-------------|-----------------|
| ST1 | 19.10.2026 | Единый центр конфигурации: подразделы с адресами `#/settings/<экран>`; экраны объявляют манифесты модулей; из операционных разделов — deep-link'и | IA предложения 19.10 (реализовано); справочники уехали из модалок разделов | SPEC.md §8, манифесты (ADR-0012) |
| ST2 | ≤18.10.2026 | Правила расчёта часов — отдельно от правил объекта (`/api/engine-settings` против `/api/settings`) | Разные домены и права | `interface/settings_api.py` |
| ST3 | ≤18.10.2026 | Версии настроек: черновик (форма и JSON — два вида одного), diff, публикация версией; валидация уровня 1 при сохранении — все нарушения разом | Ошибки конфигурации видны до публикации | `engine_settings_versions` |
| ST4 | ≤18.10.2026 | Дата версии настроек не ограничена 1-м/16-м числом — версия выбирается по дате начала периода | Гибкость границ периодов | `base_version(db, period.start)` |
| ST5 | 25.10.2026 | Публикация настроек под замком: вторая одновременная — 409; удаление кода Табеля сверяется с версией на дату новой версии | Гонки публикации и удаления кода | батч 6115788 (CHANGELOG 25.10.2026) |
