# Исправления 27.09.2026 (по ревью)

## Фронтенд (static/js/app.js)
- Таймеры опроса больше не удваиваются каждые 30 с («Мой день», «Посещения»): интервал
  создаётся один раз через `poll(view, fn)` при открытии раздела.
- Опрос на паузе, когда вкладка/PWA свёрнута; при возврате — мгновенное обновление.
- Кнопка отметки шлёт явный `in`/`out` и защищена флагом `punchInFlight` от двойного тапа;
  фоновое обновление не перерисовывает кнопку во время отправки.
- `api()`: таймаут 20 с, понятные сообщения «нет связи»/«сервер не ответил»;
  спиннер загрузки — через счётчик активных запросов.
- «Сегодня» (`todayISO`) считается по часам объекта (сервер), а не по поясу телефона.
- Минимальная длина нового пароля — 8 символов.
- Регистрация Service Worker + уведомление о новой версии.

## PWA
- `static/sw.js`: кэш оболочки приложения (офлайн открывается), API — всегда сеть.
- PNG-иконки 192/512 + maskable + apple-touch-icon; `id`/`scope` в манифесте; iOS meta-теги.
- При выпуске новой версии меняйте `VERSION`/`?v=` в `sw.js` и `index.html` одновременно.

## Бэкенд
- `POST /api/punches`: повторный IN при открытой смене → 409; `auto` в течение 60 с после
  предыдущей отметки → 409 (двойной тап); отметки одного сотрудника сериализуются блокировкой.
- Режим «как сотрудник»: права понижаются до сотрудника (менеджерские API закрыты).
- Смена пароля инвалидирует все прежние сессии (`users.token_version`), текущая переоформляется.
- Логин: одинаковое время ответа для существующего и несуществующего логина.
- GZip, заголовки `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`,
  `Cache-Control: no-store` для `/api/*`.
- Индекс `punches(employee_id, ts)`; `/sw.js` и манифест отдаются с корня без кэша.
- Миграция колонки `users.token_version` и индекса — автоматически при старте.

## Не сделано (требует решений)
- Офлайн-очередь отметок (IndexedDB + синхронизация) — нужна политика доверия к времени клиента.
- Хранение времени в UTC — затрагивает весь движок табеля.
- Rate-limit логина, CSP, Alembic, разбивка app.js на модули.
- `ALLOW_IMPERSONATION` оставлен включённым по умолчанию (демо-режим) — в проде выключите в .env.
- Блокировка отметок работает в пределах одного процесса uvicorn (для нескольких воркеров
  нужен PostgreSQL + SELECT … FOR UPDATE).
