# Отметки: «По графику сегодня» в карточке — в часовом поясе объекта (16.10.2026)

## Дефект

В карточке открытой сессии вкладки «Отметки» строка «По графику сегодня»
показывала окно смены со сдвигом часового пояса: у Громовой О.П. при смене
08:00–20:00 (MSC) выводилось 05:00–17:00, то есть часы UTC. Строки «На работе с»
и «Уже работает» были корректны: `open_since_hm` и `expected_at_hm` доска всегда
конвертировала в пояс объекта, а вот отрезки смены `shift_today` отдавались
сырыми UTC-моментами, и фронтенд резал из них `HH:MM` прямым срезом
`iso.slice(11, 16)`.

Смежные места проверены и не затронуты: гант «Месяц» слоя 2 отдаёт сессии
уже в локальном времени (`astimezone(TZ)`), линия «сейчас» синхронизируется
через `serverShiftMs` по локальному времени сервера, история «Сотрудник»
использует `start_local`/`end_local`.

## Решение владельца (16.10.2026)

Карточка обязана показывать окно в поясе объекта; UTC-моменты в API сохраняются
как источник для расчётов и не переименовываются задним числом.

## Изменения

* `app/engine/interface/views.py` — `board_dict` добавляет поле
  `shift_today_hm`: пары готовых `HH:MM` отрезков смены, конвертированные
  в часовой пояс объекта (`ZoneInfo(tz)`), по образцу `open_since_hm`.
  Сырые UTC-моменты `shift_today` остаются в ответе без изменений.
* `static/js/section_v4.js` — карточка Отметок собирает строку «По графику
  сегодня» из `shift_today_hm`; срез `slice(11, 16)` из UTC-моментов убран.
* `tests/test_presence_board.py` — регрессия
  `test_board_card_shift_today_hm_in_object_tz`: смена 08:00–20:00 MSC
  (05:00–17:00 UTC) обязана дать `shift_today_hm == [["08:00", "20:00"]]`
  и `open_since_hm == "09:00"`, при этом `shift_today` — прежние UTC-моменты.
