# Шаблоны документов (.docx): как редактировать

Система заполняет кадровые документы (заявления на отпуск и т.п.) из **ваших**
.docx-шаблонов: шрифты, логотип, подложка, колонтитулы и таблицы полностью сохраняются —
подставляется только текст вместо плейсхолдеров `{в фигурных скобках}`.

## Как сделать шаблон (рекомендуемый порядок)

1. **Настройки → «Виды заявлений и шаблоны»** — выберите вид заявления (или создайте
   свой: «+ Новый вид заявления») → **«Изменить» → «Пример .docx»**: скачается
   готовый образец со всеми основными плейсхолдерами (для своего вида — его собственный текст).
2. Откройте файл в Word, Pages или LibreOffice Writer.
3. Замените содержимое на ваш фирменный бланк: вставьте логотип, нужные шрифты,
   реквизиты. В местах, куда должны попасть данные сотрудника, **оставьте или впишите
   плейсхолдеры** — просто текстом в фигурных скобках, например `{full_name_genitive}`.
4. Сохраните как **.docx** (не .doc и не .pdf).
5. В модалке вида нажмите **«Загрузить .docx»** и выберите файл.
   Система сразу покажет, какие плейсхолдеры найдены в шаблоне.
6. Проверка: в графике откройте ячейку с отпуском → **«Заявление DOCX»**.

Повторная загрузка файла того же вида заменяет предыдущий бланк. Кнопка «Удалить бланк»
возвращает печать текстом из карточки вида.

**Виды заявлений — расширяемый справочник** (таблица `statement_kinds`, панель
«Настройки → Виды заявлений и шаблоны»). Встроенные виды создаются при первом запуске;
свои добавляются кнопкой «+ Новый вид заявления» (код — строчная латиница, название,
текст с плейсхолдерами). Каждому виду можно загрузить свой бланк `templates/<код>.docx`:

| Код | Документ (встроенные) | Файл в `templates/` |
|---|---|---|
| `vacation_paid` | Заявление на ежегодный оплачиваемый отпуск | `vacation_paid.docx` |
| `vacation_unpaid` | Заявление на отпуск без сохранения заработной платы | `vacation_unpaid.docx` |
| `day_off_hours` | Заявление на выходной за ранее отработанные часы | `day_off_hours.docx` |
| `time_off_request` | Заявление об отсутствии на рабочем месте («отпросился с … до …») | `time_off_request.docx` |
| свой код | любой вид, который вы создали | `<код>.docx` |

Какому виду отсутствия из словаря смен какой документ соответствует — настраивается
в словаре (Настройки → Смены → поле «Заявление», список берётся из справочника видов).
Кнопки печати появляются в ячейке графика только у тех отсутствий, где вид заявления указан.
Удаление вида из справочника отвязывает его от смен словаря и стирает бланк.

Файлы хранятся на сервере в папке `templates/` — можно заменять их и напрямую на диске,
изменения подхватятся при следующем формировании документа (перезапуск не нужен).

## Правила оформления плейсхолдеров

- Пишите их обычным текстом: `{full_name}`. Никаких «полей» Word (Field, MergeField,
  «Экспресс-блоки») использовать не нужно — система их не распознаёт.
- Плейсхолдер можно разрывать форматированием (Word сам разбивает текст на части при
  правке) — система склеивает соседние фрагменты, это нормально.
- Работают плейсхолдеры в абзацах, **таблицах, верхнем и нижнем колонтитулах**.
- **Не работают** плейсхолдеры внутри текстовых полей (Text Box / «Надпись») и фигур —
  Word хранит их в отдельном слое. Если нужен текст поверх рамки — используйте таблицу
  с прозрачными границами.
- Всё оформление (шрифт, размер, цвет, отступы) берётся из **первого символа** строки
  с плейсхолдером и сохраняется для всего подставленного значения.
- Значение может содержать перевод строки (например, `{director}` из настроек) —
  строки корректно переносятся внутри абзаца.

## Все доступные переменные

| Плейсхолдер | Что подставляется |
|---|---|
| `{company}` | название организации (Настройки → Шаблоны документов) |
| `{director}` | кому адресовано, шапка (там же) |
| `{full_name}` | ФИО полностью, именительный падеж: «Федоренко Николай Сергеевич» |
| `{full_name_genitive}` | ФИО в **родительном** падеже: «от Федоренко Николая Сергеевича» |
| `{short_name}` | краткое имя: «Федоренко Н.С.» |
| `{position}` | должность на дату документа |
| `{tab_number}` | табельный номер |
| `{group}` | блок графика (Смена 1 / Смена 2 / Пятидневка / Другие смены) |
| `{nationality}` | гражданство сотрудника (из карточки) |
| `{department}` | департамент из справочника подразделений (из карточки) |
| `{subdivision}` | служба/подразделение из официальных документов («Служба управления виллами») |
| `{phone}` | телефон сотрудника |
| `{telegram}` | логин Telegram |
| `{email}` | рабочая почта |
| `{emergency_name}` | экстренный контакт (имя) |
| `{emergency_phone}` | экстренный контакт (телефон) |
| `{date_from}` | начало периода, ДД.ММ.ГГГГ |
| `{date_to}` | конец периода, ДД.ММ.ГГГГ |
| `{date_from_ru}` | начало прописью: «01» октября 2026 г. |
| `{date_to_ru}` | конец прописью |
| `{days}` | количество календарных дней цифрой |
| `{days_word}` | количество прописью: «двенадцать» |
| `{today}` | дата составления, ДД.ММ.ГГГГ |
| `{today_ru}` | дата составления прописью |
| `{from_time}` | «отпросился» — время начала отсутствия, ЧЧ:ММ |
| `{until_time}` | «отпросился» — время конца отсутствия, ЧЧ:ММ |
| `{hours}` | сколько часов отсутствует (цифрой: «2» или «2,5») |
| `{hours_word}` | сколько часов прописью: «два» |
| `{period}` | период одной строкой: «с 01.10.2026 по 05.10.2026» (или одна дата) |
| `{period_ru}` | период прописью |
| `{reason}` | вид отсутствия из словаря («Отпуск», «Выходной за часы»…) |
| `{note}` | примечание из ячейки графика (номер приказа, причина) |

Незнакомый плейсхолдер остаётся в документе как есть — так легко заметить опечатку.

## Родительный падеж ФИО

В заявлениях пишется «от Федоренко Николая Сергеевича» — поэтому в **карточке
сотрудника** (Сотрудники → карточка → Изменить) есть отдельное поле
**«ФИО в родительном падеже»**.

- Заполните его вручную — это значение всегда приоритетно.
- Кнопка **«Подсказать»** предложит автоматический вариант по правилам русского языка
  (Федоренко → Федоренко, Иванов → Иванова, Анна → Анны, Ильинична → Ильиничны,
  Толстая → Толстой). Автоподсказка покрывает типичные случаи, но **проверяйте
  окончание фамилии** — редкие и иностранные фамилии могут склоняться неверно.
- Если поле пустое, документы подставят автоматический вариант (в карточке он показан
  с пометкой «подставляется автоматически»).

Тот же плейсхолдер `{full_name_genitive}` работает и в простых текстовых шаблонах
(Настройки → «Шаблоны документов (заявления)») для кнопки «Печать заявления».

## PDF (генерируется на сервере, готов к печати)

Кнопка **«Заявление PDF»** в ячейке графика собирает PDF **на сервере** и открывает его
в новой вкладке браузера — оттуда документ сразу можно отправить на печать.

Порядок сборки:

1. **LibreOffice** (`soffice`), если установлен — PDF получается один в один как ваш
   .docx-бланк (шрифты, логотип, колонтитулы):

   ```bash
   brew install --cask libreoffice       # macOS
   sudo apt install libreoffice-writer   # Ubuntu/Debian (достаточно writer)
   ```

2. Без LibreOffice работает **встроенный рендер** (reportlab + шрифты DejaVu из
   `assets/fonts/`): документ собирается по тексту шаблона (загруженного .docx или
   встроенного из настроек) — без фирменной подложки, но с корректным русским текстом
   и всеми плейсхолдерами. Зависимость `reportlab` уже есть в `requirements.txt`,
   шрифты лежат в репозитории — доустанавливать ничего не нужно.

Статус PDF виден в Настройки → «Шаблоны документов компании» (`libreoffice`,
`native` — встроенный рендер, или «недоступен»). DOCX работает всегда.
