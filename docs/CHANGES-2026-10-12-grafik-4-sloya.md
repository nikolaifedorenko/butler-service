# Обновление v2.1 (12.10.2026) — решения владельца по Q1–Q9 и два замечания

Владелец ответил на вопросы ревью и дал два замечания. Код приложения по-прежнему **не менялся** —
обновлены прототип, смоук и документ-ревью (PR #9, та же ветка).

## Решения владельца (учтены)

1. **Замечание 1 / Q4 / Q6 — «недопуск» не добавляется** («забудь пока; если будет надо — я введу
   в табель новый код»). Из прототипа убраны: кнопка «Недопуск к работе» в модалке Графика,
   тип отсутствия NOT_ADMITTED, код «НД» в словаре, ⛔ в легенде. Задача T2 снята.
2. **Замечание 2 — деление переработок ДЯ/ДН (06:00–22:00) идёт из настроек**. Движок уже читает
   границы категорий из конфигурации; в прототипе они вынесены в явные константы `CFG.dayFrom/dayTo`
   с пометкой, упоминание «из настроек» добавлено в слои «Факт» и «УТ» и в «Схему».
3. **Q1 решён (главное противоречие снято)**: стандартное окно жёстко привязано к коду Табеля;
   в Графике по умолчанию табельное окно, замена — ручные смены из справочника; ручная смена
   (в т.ч. ночная) на Табель и часы не влияет. Переключатель режима окна убран из прототипа;
   добавлено демо: Петров 06.10 — ночная смена 20:00–08:00 в Графике, окно 08:00–20:00 и часы
   (план 12ч / факт 12ч) из кода Табеля «Я 10,75» без изменений. Задача T6 снята.
4. **Q2–Q5, Q7, Q8 подтверждены**: пункт меню «График»; «отпросился» = «выходной за часы» — одна
   сущность; из Графика только «за счёт часов»; «Сбросить» — как в прототипе; доска — отдельный
   пункт меню; отпрос информационный — неотработанные часы окна уходят в недостачу.
5. **Q9**: модель «код Табеля → стандартное окно → первоначальные смены Графика» подтверждена;
   T1 переформулирована как техническая починка поля «код в табеле» (редактор пишет туда короткое
   имя смены «08-20» — должны быть только коды словаря Табеля или пусто).
