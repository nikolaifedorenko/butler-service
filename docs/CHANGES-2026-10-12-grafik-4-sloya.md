# Изменения 12.10.2026 — прототип «График = 4 слоя» и ревью норматива

Вечерний батч после слияния PR #8. Код приложения (движок, API, интерфейс) **не менялся** —
добавлены только документ-ревью, автономный прототип и его смоук.

## Что добавлено

1. **`docs/REVIEW-GRAFIK-4-SLOYA-2026-10-12.md`** — ответ на нормативное сообщение владельца
   от 12.10.2026 (четырёхслойный «График»: Табель → План/График → Факт → Управленческий Табель):
   - соответствие слоёв и движка v7.1 (что уже реализовано / что нужно построить, задачи T1–T6);
   - проверка обоих числовых примеров владельца на реальном движке (совпали точно);
   - открытые вопросы Q1–Q9 с рекомендациями (главный — Q1: противоречие «ручное окно» vs
     «График не влияет на часы»);
   - риски (APP-SHIFT-CODE блокирует автозаполнение ночных/суточных) и порядок работ (PR-A/B/C).

2. **`docs/grafik-4-sloya-prototype.html`** — автономный интерактивный прототип (инлайн CSS+JS,
   без сервера и внешних ресурсов): один пункт меню «График», внутри четыре слоя + «Схема».
   Демо-период 01–14.10.2026, три сотрудника, воспроизведены оба примера владельца;
   переключатель режима ручного окна («как сейчас» / «предложение»), шаг округления 15/30/60,
   «Сбросить» в Табеле, модалка дня Графика (отпрос на всю смену, недопуск), закрытие периода
   (банк 1:1, каскад, перенос). Генератор прототипа: `proto/build_layers.py` (вне репозитория,
   в рабочей песочнице) — при правках пересобирать и прогонять смоук.

3. **`tools/proto_layers_smoke.mjs`** — смоук прототипа в jsdom (108 проверок): каркас, слои,
   числовые примеры (Петров 05.10: 12ч/11ч30м/30м/ДЯ 30м; Иванова 05.10: 9ч/8ч/1ч→банк/ДЯ 5ч+ДН 1ч),
   закрытие периода, схема. Запуск: `npm run smoke:proto`.
