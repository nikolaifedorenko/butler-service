# Движок v4 (2026-10-06)

Реализация спецификации `docs/overtime_spec_v4.md`.

## Архитектура
`app/engine/`: `domain` (чистые функции: размещение кодов Т9, банк, каскад Т6, флаги, инварианты И1–И19) → `ports` → `application` (view / close / recalculate, доска присутствия) → `adapters` (SQL) → `interface`.

## Вкладки
- Кто на работе / Посещения — счётчики «Сейчас на работе», «По графику сегодня»; списки: на работе, отлучился (ожидается), ожидается к приходу.
- График — просмотр и редактирование (право `schedule.edit`).
- Табель — отдельный документ (`tabel_days`), редактирование ячеек, «Заполнить из Графика».
- Управленческий табель — режимы `view` (расчёт на лету) и `close` (закрытие, пересчёт последнего закрытого), Excel.
- Права доступа — роль → группы (запрет сильнее) → индивидуальные права.
- Журнал аудита — фильтры, CSV.

## Настройка
- Коды Табеля, модификаторы, группы, Т9 — «Настройки → Справочники движка» (версии с датой действия).
- Модификаторы дня (Т4) — там же; приоритет: сотрудник+день → … → все+период.

## Удалено
Старый `timesheet.py`, ворота отметок, правила округления, CSV/PDF табеля (заменены Excel УТ).

## Тесты
