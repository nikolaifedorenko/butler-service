# Изменения 18.10.2026 — упрощение раздела «Настройки»: независимые справочники, значение рабочего дня у сотрудника

Задание владельца от 17.10.2026 (продолжение очереди 16.10.2026): убрать дублирование
настроек кодов Табеля, сделать График зеркалом Табеля, перенести окна/значения в карточку
сотрудника и облегчить базовый цикл. Концепт и оценка рисков согласованы до реализации
(решения владельца: флаги кодов НЕ удаляются; Смена 2 всегда в противофазе; старые виды
отсутствий удаляем физически — боевой базы нет).

## 1. Коды Табеля: список без дублирования (только визуальный слой)

* Общий список (`settingsCodesCards`) — строка: пилюля + название + «Изменить» + «✕».
  Флаги («Несёт часы», «Принимает коды УТ», «Учитывается в УТ», «План=Факт = Авто»),
  режим отметок «Пришёл/Ушёл» и шаблон заявления настраиваются ТОЛЬКО в модалке
  «Изменить» и на вкладке «Окна и значения» — из списка убраны.
* Логика, серверные проверки отметок (`_punch_permissions`) и спека v7.1 не менялись.

## 2. Смены и отсутствия: словарь ячеек Графика

* Словарь независим от Табеля: поля `tzh_code`, `display_code`, `deduct_from_bank`
  удалены из `shift_types` и `shift_revisions` (миграция
  `migrate_schedule_dict_simplify`), API и редактор смены их больше не принимают.
* Виды отсутствий (SICK, VACATION, VACATION_UNPAID, PAID_OFF, ABSENT_UNKNOWN, OFF)
  удалены миграцией; согласованные отсутствия Графика перепривязаны на системный вид
  `TIMEOFF_HOURS` «Отпросился (выходной за часы)» (цвет плашки #0e9aa7).
* Отсутствия периодом назначаются кодом Табеля напрямую (`range-absence` + `code`).
* Модалка «Новая смена / отсутствие»: код, название, начало/конец, цвет, тип;
  «Заявление (печать из ячейки графика)» показывается только для типа «отсутствие»;
  чекбокс банка часов убран (банк гасит недостачу дня механически, домен `bank/`
  флаг не читал).
* График по умолчанию — копия смен Табеля: цвет ячейки разрешается сервером
  (`_cell_color`): плашка — цвет системного вида, смена — цвет словарной смены с тем же
  окном, день без смены — цвет кода Табеля из presentation.
* Ячейка Графика, диалог «Отпросился»:
  * интервал — показ рабочего времени ДО и ПОСЛЕ интервала (`#cell-abs-split`);
  * всё окно — плашка «Выходной за часы» цветом из настроек словаря;
  * выбор шаблона заявления в диалоге (`schedule_absences.doc_type`, новый столбец +
    поле `doc_type` в `POST /api/schedule/absence`); выбранный шаблон первее правила
    по точке входа (`doc_type_of_absence`); печать DOCX/PDF — из Графика как раньше.
* Health: сверки APP-SHIFT-CODE и APP-CODE-NO-SHIFT удалены вместе со связкой;
  публикация версии по-прежнему не даёт удалить код, стоящий в Табеле.

## 3. Заполнение Табеля: значение рабочего дня сотрудника

* `tabel_fill.value_for_day` переписан: цикл (base/week5/cycle) отвечает только
  «рабочий ли день» (`working_flag`), код и план берутся из значения сотрудника
  (`pattern_for_date → value`, ключ CFG-WINDOWS). Нормы прежние: якорь для смен через
  полночь, окно не пересекает полночь (CHK-WINDOW-BOUNDS), выходной — «В», дни вне
  трудоустройства не заполняются.
* Значение живёт в `BlockAssignment.pattern_json → "value"`; fallback — значение блока
  в настройках объекта (`base_groups`). Новый эндпоинт списка значений —
  `GET /api/tabel-values` (коды, несущие часы: значение, часы, окно).
* Диалог «Перевод в блок» и приём на работу: селект «Значение рабочего дня»;
  история переводов и карточка показывают блок + текущее значение
  (`/api/employees/{id}/history → current_value`).
* `POST /api/schedule/fill-pattern` принимает `value` вместо `work_shift_id`.
* Предупреждения заполнения: значение не задано / отсутствует в CFG-WINDOWS / код не
  несёт часов — день не заполняется, текст уходит в warnings и в health
  (APP-EMP-NO-VALUE).

## 4. Группы и графики / базовый цикл

* Экран «Базовый цикл объекта»: только цикл смен и опорная дата. Селекты смен блоков
  и чекбокс противофазы убраны: «Смена 2 всегда в противофазе» — системное правило
  (`pattern_for_date`: invert для «Смены 2» константой).
* `PUT /api/settings/base` сохраняет значения/выходные блоков как есть (экран их не
  редактирует; правка — в карточках сотрудников).

## 5. Миграция и совместимость

* `migrate_schedule_dict_simplify()` (старт сервера, идемпотентна): паттерны блоков и
  `base_groups` получают `value`, вычисленное из прежней связки «смена → код → окно»;
  отсутствия Графика перепривязаны на TIMEOFF_HOURS; виды отсутствий и их ревизии
  удалены; столбцы связки drop; `schedule_absences.doc_type` — ADD COLUMN.
* Исторические миграции, трогавшие удалённые столбцы (`_migrate_missing_shifts`,
  `_migrate_remove_sick_unpaid`, `migrate_shift_tabel_codes`, нормативные UPDATE
  tzh_code), переведены в no-op с комментариями.
* Тесты: 548 зелёных; обновлены контракты fill-pattern/shift-types/range-absence,
  health-проверки, цвета плашки, словарь смен в интеграционных тестах.
