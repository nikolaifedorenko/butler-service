# Изменения 16.10.2026 (батч 2) — ручная смена замещает генерацию; цветные PDF/Excel; без «Итого»

Продолжение батча «Сетка слоя 1» (PR #31) по отзыву владельца: найден и исправлен
сквозной дефект ручной смены, PDF и Excel приведены к экранному виду (цвета из
словаря), итоговая колонка часов убрана.

## Дефект: ручная смена не вытесняла генерацию дня (сквозной, до 16.10.2026)

Кейс владельца: у Громовой смена из Табеля 08:00–20:00, сделана ручная смена
09:00–18:00 и интервал 14:00–16:00 — в ячейке оказалось ЧЕТЫРЕ строки
(08:00–14:00, 16:00–20:00, 09:00–14:00, 16:00–18:00): смена из Табеля не пропала.

Причина в движке (16.3 «ручная смена заменяет генерацию дня целиком» не
выполнялось): `save_manual` удалял только прежние РУЧНЫЕ строки дня, а
`rebuild_generated_schedule` перегенерировал все дни с окнами, не проверяя
ручные смены — обе строки (generated + manual) сосуществовали. Прежняя сетка
показывала их одной строкой («Я 12 08:00–20:00 09:00–18:00»), и дефект не
бросался в глаза; новый построчный вид сделал его заметным. Доска «Отметки» и
флаги тоже читали обе записи.

Исправление (единственное место правила — application-слой движка):

* `save_schedule_day`: перед записью ручной смены generated-строки дня удаляются
  (`replace_generated(day, ())`) — замещение мгновенное;
* `rebuild_generated_schedule`: дни с ручной сменой (якорь — день начала)
  НЕ регенерируются; якорные дни собираются одним чтением периода (без N+1);
* `DELETE /api/schedule/shift`: после удаления ручной смены день возвращается
  к генерации явным rebuild (раньше «возврат» работал случайно — за счёт того,
  что generated-строка и не удалялась);
* `reset-month`/`clear-month`: `db.flush()` перед rebuild — сессия с
  `autoflush=False`, иначе regeneration видел неудалённые строки;
* миграция `migrate_manual_replaces_generated`: из старых баз удаляются
  generated-строки дней, где стоит ручная смена (идемпотентно) — дубль Громовой
  исчезнет при старте сервера.

## Цвета словаря — в PDF и Excel (были только на экране)

* `GET /api/schedule` разрешает цвет ячейки СЕРВЕРОМ (`cell.color`): плашка —
  цвет вида отсутствия; смена — цвет словарной смены с тем же окном (первая по
  id); код без смены — цвет вида по `tzh_code`; запасной — цвет кода Табеля
  (presentation настроек, общий сервис `day_code_colors` — API-модули не
  импортируют друг друга, контракт import-linter соблюдён). Экран, печать, PDF
  и Excel теперь красятся из ОДНОГО источника; фронтовый матчинг остался только
  подстраховкой кеша.
* `grid_docx.schedule_docx` (PDF): подложки ячеек — тон словарного цвета
  (`tint_hex`, смешение с белым 22% — как `withAlpha` на экране).
* `export_xlsx` (Excel): тот же вид ячейки, что на экране — `cell_plan_text`
  (плашка «Выходной за часы» / отрезки по строкам / код Табеля), заливка цветом
  словаря, переносы строк и центрирование.

## «Итого»/«Часов» убраны

Колонка итоговых часов удалена из экранной сетки, браузерной печати, PDF и
Excel (решение владельца 16.10.2026); в подписи строки осталось только число
смен. Payload `totals` сохранён (число смен в имени, будущие потребители).
