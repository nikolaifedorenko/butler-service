Слой 2 · Факт — вкладка «Месяц» (прототип)

Гант фактических присутствий: сессии из отметок СКУД, округлённых до шага («пришёл — ушёл»), на непрерывной оси времени месяца — смена через полночь рисуется одной полосой. Ночные часы (22:00–06:00) — темнее основного цвета полосы; стандартное окно значения Табеля — штриховкой того же цвета; разрыв полосы = уход/отлучка по отметкам; бирюзовая плашка с ✂ = согласованное отсутствие; день без смены («В», «ОТ», «Б») — тонированная ячейка с кодом. Цвета — из словаря «Смены и отсутствия», те же, что в ячейках Графика.
