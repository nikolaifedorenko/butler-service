# Быстрые правки безопасности — 15.10.2026

По итогам аудита кодовой базы (пункты 1–4 плана).

## 1. Выход отзывает сессию
* `POST /api/auth/logout` увеличивает `users.token_version`: скопированная или украденная
  cookie после выхода больше не принимается (раньше работала до 14 суток).
* Следствие: выход на одном устройстве завершает сессии пользователя на всех устройствах.
* Срок сессии по умолчанию — **48 часов** (`SESSION_TTL_HOURS`, было 14 суток).

## 2. Цвета — только `#rgb` / `#rrggbb`
* `EmployeeIn.group_color` и `ShiftTypeIn.color` проверяются на бэкенде
  (`app/deps.normalize_hex_color`), иначе 422.
* Фронтенд: `cssColor()` в `core.js` — все цвета из БД, попадающие в `style="…"`,
  проходят через неё (сетка Графика, список сотрудников, Настройки). Старые
  некорректные значения в БД заменяются цветом по умолчанию.

## 3. Миграция v7.1 без автоочистки
* `migrate_engine_v7()` больше не выполняет `DELETE FROM` по расчётным таблицам при
  отсутствии маркера `engine_v7_reset`: маркер только записывается, в лог — предупреждение.
  Восстановление бэкапа без этой строки больше не стирает Табель, смены и закрытия.

## 4. `/api/selfcheck` не раскрывает схему
* Без входа и для не-админов — только `ok` / `hint`; перечень недостающих таблиц и
  колонок (`missing`, `tables_*`) — только администратору.
