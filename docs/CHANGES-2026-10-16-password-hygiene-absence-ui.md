# Изменения 16.10.2026 (батч 4) — гигиена пароля и упрощение блока «Отпросился»

Четыре правки владельца по интерфейсу.

## 1–2. Плашка «сохранить пароль» и пароль после выхода

Скрытая форма логина (`#login-screen`) живёт в DOM всю сессию. Введённый пароль
оставался в её поле, и менеджеры паролей браузера реагировали на оставшееся
значение в «логин-форме» всплывающим предложением сохранить пароль при
переключениях разделов (владелец видел его при открытии «Настроек»); после
выхода поле пароля оставалось заполненным.

* пароль очищается сразу после успешного входа (`#login-form` submit);
* `showLogin()` (выход и 401-путь) очищает поле пароля;
* autocomplete-атрибуты формы (`username` / `current-password`) уже были
  корректными — источник проблемы именно в оставшемся значении.

## 3. «Вид отсутствия» в ячейке Графика убран

Из Графика назначаются только виды «за счёт часов» (Q4), а такой вид в словаре
один — выбирать не из чего. Селект «Вид отсутствия» (с сбивающим «— без вида —»)
убран из редактора ячейки: `kind_id` берётся из единственного вида словаря;
кнопки «На интервал» / «На всю смену» и часы «выходного за часы» доступны сразу.
Попутно ушёл старый баг `syncAbsKind`: кнопка «На всю смену» показывалась и при
«— без вида —», потому что проверялся сам элемент `option`, а не его значение.

В модалке периода («Выходной за часы» из панели инструментов) вид в режиме
Графика тоже больше не выбирается — показывается названием вида; в режиме
Табеля (`Назначить отсутствие`) селекты сохранены: там осмысленный выбор
ОТ/ДО/Б/ОВ с кодами первичного документа.

## 4. Блок «Отпросился…» — только при смене с часами

Согласованное отсутствие режет смену (логический разрез, v7/R17): в день без
смены («В», пустой Табель) назначать его не к чему. Блок ввода (интервал /
вся смена) показывается только когда в дне есть смена с часами — ручная или
сгенерированная из Табеля; иначе — короткое объяснение, куда идти (смена
плашками здесь же, отсутствие дня кодом Табеля в слое 0). Список уже
назначенных отсутствий показан всегда: удалить и напечатать заявление можно.
