# Изменения 16.10.2026 (батч 6) — слой 2 «Факт»: вкладка «Месяц» (гант фактических присутствий)

Решение владельца 16.10.2026: в слое 2 нужна месячная картина фактических
присутствий — не таблицей, а **гантом** на непрерывной оси времени; заодно
переименованы вкладки «Номера» → «День», «Сессии» → «Сотрудник» (логичнее
отражают содержимое).

## Прототип

Сначала нарисован прототип: `docs/prototype-fact-month-gantt.html` —
самодостаточная страница (мок-данные в формате будущего ответа API), тот же
рендерер перенесён в `section_v4.js`. Владелец видел прототип до PR.

## Вкладка «Месяц»

* **Ось X — непрерывное время месяца** (не колонки календарного дня): смена
  через полночь рисуется ОДНОЙ полосой. Данные — новый `GET /api/fact/month`:
  сессии сопряжением ОКРУГЛЁННЫХ отметок (`to_calc_mark` + `pair_marks` — то же
  ядро, что у вкладки «День»), целиком, без нарезки полуночью; settle/расчёт не
  запускается (ганту не нужны план/недостача — только присутствия).
* **Ночные часы 22:00–06:00 — темнее** основного цвета полосы: видно, кто работал
  в ночь; фон ночных часов подсвечен и на полотне.
* **Стандартное окно значения Табеля — штриховкой** того же цвета: ранний уход /
  опоздание / неотработанные часы видны как штриховка без полосы; окно через
  полночь рисуется двумя кусками.
* **Разрыв полосы = уход/отлучка по отметкам**; согласованное отсутствие —
  бирюзовая плашка с ✂ поверх окна; «выходной за часы» на весь день — штриховка
  окна без полосы (+ плашка ✂).
* **Цвета — из словаря «Смены и отсутствия»**, те же, что в ячейках Графика:
  резолвер вынесен в сервис (`color_lookups`/`pick_cell_color` в
  `services/engine_common`) и используется Графиком и Гантом одинаково; цвет дня
  берётся по смене с якорем в этом дне (ночная полоса, заходящая на соседний
  «В», не перекрашивает его код).
* День без смены — тонированная ячейка с кодом Табеля (В/ОТ/Б…); открытая сессия
  («идёт сейчас») — полоса с пунктиром; линия «сейчас» — по часам объекта.
* Права: `presence.view`; сотруднику — только своя строка (как в «День»).

## Переименования вкладок слоя 2

«Месяц» между ними. Подсказки и легенды приведены к новым именам.
