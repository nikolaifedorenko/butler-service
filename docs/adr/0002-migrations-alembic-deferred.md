# ADR-0002. Миграции: самодельные idempotent-шаги, Alembic отложен

**Статус:** принят 15.10.2026 (риск 🟠 в ARCHITECTURE.md остаётся открытым)

## Контекст
`app/migrations.py` (~500 строк) выполняет raw-DDL при каждом старте:
`CREATE INDEX IF NOT EXISTS`, точечные `ALTER TABLE ADD COLUMN`, backfill.
Шаги идемпотентны и проверены прогонами; но нет версионирования, отката и
autogenerate.

## Решение
Сейчас — оставить как есть (шаги идемпотентны, стартовый guard `_check_secret_key`
выполняется ДО миграций). Переход на Alembic — отдельный проект: stamp текущей
схемы как `alembic baseline`, перенос шагов в ревизии, удаление raw-DDL из
`init_db`. Не делать «между делом»: цена ошибки — данные прода.

## Последствия
До перехода: новые изменения схемы добавлять идемпотентными шагами
(образец — `migrate_engine_v7`) и дублировать в `models.py` (индексы/колонки).
План перехода зафиксирован в ROADMAP (п. P0-3).
