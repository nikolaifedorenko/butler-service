# ADR-0001. Записи архитектурных решений (ADR)

**Статус:** принят 15.10.2026

## Контекст
«Почему» решений раньше жило в `docs/CHANGES-*.md` (хронология) и
`docs/architecture/ARCHITECTURE.md` (срез). Найти обоснование конкретного
выбора по номеру/теме было нельзя.

## Решение
Завести `docs/adr/`: один файл на решение, нумерация сквозная, статусы
«принят / заменён ADR-N». Формат: Контекст → Решение → Последствия.
CHANGES остаются хронологией релизов, ARCHITECTURE — текущим срезом.

## Последствия
Новые значимые решения (форматы токенов, хранилища, границы слоёв, лимиты)
оформляются ADR до или вместе с реализующим PR.
