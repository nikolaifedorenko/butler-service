# ADR-0005. Rate-limit входа: таблица в БД (пересмотрено 22.10.2026)

**Статус:** принят 15.10.2026 («in-memory per-worker, Redis отложен»), **пересмотрен 22.10.2026**
(фаза 5 аудита, находка SEC-01): счётчик перенесён в таблицу `login_attempts`.

## Контекст
Лимит «10 неудач / IP / 5 минут» жил в словаре процесса. При N воркерах каждый вёл свою копию
(фактический лимит ×N), при нескольких контейнерах — тоже. Прод-профиль запускает 2 воркера,
а аудит предлагал выносить в общее хранилище всё состояние между воркерами.

## Решение
* Неудачная попытка — строка `login_attempts(key, ts)`, `key = "ip:<адрес>|user:<логин>"`.
  Проверка — `COUNT` строк за окно: 10 на пару «адрес + логин» и 50 на адрес целиком (перебор по
  разным логинам). До 22.10.2026 ключ был только адрес, и успешный вход сбрасывал счётчик всего
  адреса: сотрудник со своей учёткой перебирал чужой пароль без остановки, а персонал за одним
  Wi-Fi блокировал вход друг другу (свежий аудит 22.10.2026).
* Запись неудачи коммитится сразу: за ней следует ответ 401, и без отдельного commit попытка
  пропала бы вместе с сессией запроса.
* Строки старше окна удаляются при записи новой неудачи — таблица не растёт, отдельная фоновая
  задача не нужна. Успешный вход удаляет строки только своей пары «адрес + логин».
* Адрес клиента — как раньше: правый адрес `X-Forwarded-For` при `TRUST_PROXY_HEADERS=1`.
* Redis не нужен: PostgreSQL одного объекта выдерживает лишний INSERT на неудачный вход.

## Последствия
* Лимит общий для всех воркеров и контейнеров одной базы. Страж —
  `tests/test_csrf.py::test_login_rate_limit_is_shared_between_workers`.
* Лимит по логину независимо от адреса не введён: им злоумышленник мог бы блокировать вход
  конкретному сотруднику. Пара «адрес + логин» этого не позволяет — блокируется только сам
  перебирающий. Стражи — `tests/test_csrf.py` (свой вход не сбрасывает чужие неудачи, потолок
  адреса).
* Точечные лимиты на другие чувствительные операции (смена пароля, массовые экспорты) — в
  backlog; их частично гасят права доступа и аудит.
