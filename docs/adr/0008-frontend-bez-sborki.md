# ADR-0008. Фронтенд без сборки: границы разделов — файлами, контракт — реестр глобалов

**Статус:** принят 15.10.2026

## Контекст
SPA/PWA на обычных скриптах без бандлера — осознанный выбор проекта (установка на
серверы заказчика без интернета, никакого node-билда в проде). Издержки:
`app.js` вырос до 2262 строк (навигация, вход, сетка Графика, заявления,
«Мои отметки», «Сотрудники», справочники Настроек в одном файле), а связи
между файлами держатся на глобальных функциях.

## Решение
1. **Сборщик НЕ вводим**, пока команда 1–2 человека: esbuild/ES-модули —
   это новый класс поломок (кэш, source maps, версионирование бандла) ради
   выгод, которые на этом масштабе даёт и файловая структура. Триггер пересмотра:
   рост команды или потребность в npm-зависимостях в рантайме.
2. **Границы — файлами по разделам** (15.10.2026): `app.js` (2262 → 369 строк:
   навигация, вход, слои Графика, старт) + `section_grid.js` (сетка, редакторы
   ячейки/периода, печать), `section_docs.js` (заявления/печать),
   `section_me.js` (PWA-кабинет), `section_employees.js` (каталог),
   `section_dicts.js` (под-экраны Настроек) — к уже существовавшим
   `section_v4/settings/night/cars.js`. Извлечение побайтово переносом кода,
   без изменений логики.
3. **Контракт связности — инструменты** (уже были, теперь покрывают 11 файлов):
   `tools/gen_js_globals.py` строит реестр глобальных имён и ПАДАЕТ на дублях;
   ESLint `no-undef` по этому реестру ловит «вызвали функцию, которой нет»;
   `tools/bump_version.py --check` — версии index.html ↔ sw.js SHELL;
   смоук интерфейса рендерит ВСЕ разделы под тремя ролями, сценарии
   (settings/norms/layers) кликают пользовательские пути.
4. Загрузочный порядок не значим: извлечённый код — только объявления функций
   и их константы; boot-код (привязки, service worker, старт) остался в `app.js`
   и исполняется отложенно (await), к моменту вызова все файлы загружены.

## Последствия
Новый раздел/экран — новым файлом `section_<раздел>.js` + тег в index.html +
`python3 tools/bump_version.py` (пересобирает sw.js SHELL) +
`python3 tools/gen_js_globals.py`. «Правки между файлами» без прогона
`npm run lint` и смоука не пушим.

## Дополнение 22.10.2026 (фаза 5 аудита, шаг 5.4): фронтенд-часть манифеста модуля
Сборщик по-прежнему не вводим. Меняется способ, которым раздел попадает в интерфейс:
* Подписи, порядок и права пунктов меню (`MenuItem`) и экранов «Настроек» (`Screen`: группа,
  порядок, право видимости, `external`) объявляет манифест модуля (ADR-0012). Сервер отдаёт их
  в `/api/auth/me` (`menu`, `settings_screens`) уже по правам пользователя. Отдельный
  `GET /api/app/manifest` из плана не понадобился: `/api/auth/me` и так запрашивается при
  входе, входе «как сотрудник» и смене прав.
* Файл раздела регистрирует загрузчики: `registerModule({views: {id: loadX},
  screens: {id: {render, icon}}})` (`app.js`). Захардкоженные `visibleTabs()`, `LOADERS` и
  `SETTINGS_SCREENS` удалены. Контейнер `#view-<id>` нового раздела создаётся сам.
* Список `<script>` в `index.html` генерирует `tools/bump_version.py`: `core.js`, `app.js`,
  затем все `static/js/modules/*.js` по алфавиту. `--check` ловит файл, которого нет в списке.
  Порядок файлов разделов не важен: ссылки между файлами при загрузке убраны (раньше
  `settings.js` требовал, чтобы `night.js` и `cars.js` были подключены раньше). Проверено
  загрузкой в jsdom в прямом и обратном порядке.
* Контракты `.importlinter`, где перечислены модули (изоляция `notify`, R3), генерирует
  `tools/gen_importlinter.py` (`--check` в CI).
* Стражи в `tests/test_modules_architecture.py`: права пунктов есть в каталоге, id не
  повторяются, группы экранов не разорваны, у каждого пункта есть `registerModule`.

Последствие: новый раздел — новый файл `static/js/modules/<раздел>.js` с `registerModule` и
пункты в манифесте модуля, затем `python3 tools/bump_version.py`,
`python3 tools/gen_js_globals.py` и `python3 tools/gen_importlinter.py`. `index.html`, `app.js`
и `settings.js` не правятся. Иконку пункта меню файл модуля может добавить в `ICONS`.

Не сделано (PERF-03): сотрудник по-прежнему скачивает все файлы разделов. Service worker
всё равно кэширует всю оболочку, а ленивое подключение файлов по правам усложнило бы вход
и имперсонацию. Вернуться к этому, если объём JS станет заметен на телефонах.
