# ADR-0007. Сессионный токен: самодельный подписной формат (не JWT), MAC 128 бит

**Статус:** принят 15.10.2026

## Контекст
`security.py`: base64url(payload) + HMAC-SHA256 от `SECRET_KEY`, дайджест
обрезан до 32 hex-символов (128 бит). TTL 48 ч (до 15.10.2026 — 14 суток), отзыв — `token_version`
(смена пароля инвалидирует все сессии пользователя).

## Решение
Формат оставить: 128-битный MAC — допустимая стойкость (NIST SP 800-107
разрешает truncation ≥128 бит для HMAC), переход на полный 256-битный дайджест
или JWT обозначил бы всем пользователям разлогин и не добавил бы практической
стойкости. Fail-fast на слабый `SECRET_KEY` (14.10.2026) закрывает главную
предпосылку подделки. JWT не нужен: алгоритмы/claims не согласуются с внешними
сторонами, проверка локальная.

## Последствия
При изменении формата — планировать принудительный разлогин (уведомление в
CHANGES). Точечный отзыв одной сессии (не всех) потребует jti-списка — в
backlog'е, текущая модель «пароль изменён → все сессии сброшены» достаточна.
