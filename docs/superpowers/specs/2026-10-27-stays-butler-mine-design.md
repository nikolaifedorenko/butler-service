# Шахматка (stays), часть 4: батлер — «свои гости», права, «Мои гости» — дизайн

**Статус:** ред. 2, 27.10.2026 — открытые вопросы закрыты ответами владельца (§8); вид экрана
«Мои гости» — вариант «В» (согласован, макет 27.10.2026). Опирается на часть 1 (месяц, фильтры)
и часть 3 (сопровождение, «Особый гость»).

## 1. Зачем

Сейчас батлер видит только брони окна «вчера … +7 дней» списком, шахматку не видит, правит свои
брони по одному праву `stays.edit_mine`. Владелец: батлер должен видеть **всех своих гостей —
прошлых, текущих и будущих**, видеть шахматку **без правки**, редактировать **карточки всех своих
гостей** (проживающих, выехавших и заезжающих). Заодно снимается находка M1 аудита
(«свои» шире спеки): окно отменяется намеренно, через права.

## 2. Решения владельца

* «Свой гость» — гость, у которого у батлера есть **хоть одна строка покрытия** (назначение на
  день) — в прошлом, сейчас или в будущем. **Без ограничения срока.** Подменный батлер — так же:
  гости, которых он вёл на подмене, остаются его навсегда.
* Брони со статусом «предварительная», на которые батлер назначен, — тоже «свои», с пометкой.
* Видеть своих гостей — **одно право** (`stays.mine`).
* Правка — **два права**: профиль гостя и бронь — отдельно.
* Шахматку батлер по умолчанию видит **на уровне «с фамилиями»** (без телефонов и ДР чужих
  гостей), без правки.
* «Мои гости»: «Сегодня» + «Мой месяц» (личная мини-шахматка с полосой нагрузки) + «Все мои
  гости» (поиск по всей истории).

## 3. Права

| Право | Что даёт | По умолчанию |
|---|---|---|
| `stays.mine` | экран «Мои гости»; полный профиль **своих** гостей и их брони на чтение | все |
| `stays.mine_guest_edit` | правка профиля своих гостей: предпочтения, особые даты, связи «кто кому», поля, примечание | все |
| `stays.mine_res_edit` | правка брони своих гостей: состав (кроме главного; новые — только связанные «кто кому»), логистика, сопровождающие, примечание, поля брони | все |
| `stays.view` | шахматки, табло, загрузка, «Брони» с фамилиями | **все** (было: старший и выше) |

* `stays.edit_mine` заменяется двумя правами; миграция выдаёт обе тем ролям, у кого было оно.
* Запертые поля брони — как сейчас (`LOCKED`: номер, даты, РЗ/ПВ, категория, метка, заказчик,
  «оплата за» (`paid_category_id`), группа; «повод визита» удалён) + `vip_code`, `escort_mode` (часть 3). Проверка «побайтово равны» —
  как сейчас.
* В профиле батлер **не** меняет «◆ Особый гость» и VIP-код (часть 3).
* Правка брони **выехавшего** гостя разрешена (дописать после выезда) — в пределах тех же полей.
* Принадлежность проверяется на каждом запросе (как сейчас).

Безопасность (строгие требования ИБ): срок не ограничен по решению владельца; доступ к
профилю чужого гостя закрыт, телефоны и ДР в шахматке у батлера — только свои. Открытия профиля
в аудит **не пишутся** — сознательное решение владельца (§8.2); журнал, как сейчас, — только
изменения.

## 4. «Свои» — вычисление

`application/mine.py`:

* `my_guest_ids(db, employee_id) -> set[int]` — гости из `CoverageGuest` строк батлера плюс
  проживающие броней/групп, которые батлер ведёт строкой «вся бронь / группа» (по правилу §4.2
  исходной спеки: явный список гостей другого батлера сильнее), за **всё время**. Один-два
  запроса, без загрузки контекста за весь период (снимает и замечание о производительности M1).
* `my_reservation_ids(db, employee_id) -> set[int]` — брони, где у батлера есть строки.
* `owns_guest`, `owns_reservation` — по этим множествам.

## 5. Экран «Мои гости» (телефон)

Макет согласован 27.10.2026.

* **«Сегодня»** — карточки гостей, которых батлер ведёт сегодня: ◆ Особый гость, VIP-код, объект (номер по
  версии дня), заезд/выезд, логистика на сегодня/завтра, предпочтения, ближайшие особые даты
  (ДР в пределах 7 дней).
* **«Мой месяц»** — личная мини-шахматка: строки — объекты своих броней в месяце, полосы по
  половинкам суток; ◀ ▶ месяц (общий с Табелем); над сеткой **полоса нагрузки** по дням (цвет:
  один гость / несколько одновременно / выше лимита); отсутствия по Графику — отметкой «О».
  Предварительные брони — бледной полосой с пунктиром, в карточке «предварительная»; в нагрузку
  идут как сейчас. Клик по полосе — карточка брони и гостей.
* **«Все мои гости»** — поиск по фамилии среди своих гостей за всё время; карточка гостя —
  профиль и история проживаний (все брони, где он жил, с отметкой «вёл я дд.мм–дд.мм / другой
  батлер»).
* Правка — кнопкой «Изменить» в карточке гостя (`stays.mine_guest_edit`) и брони
  (`stays.mine_res_edit`); без права кнопки нет.

## 6. Шахматка у батлера

* Видит все вкладки уровня «с фамилиями» без правки: ни создания броней, ни назначений, ни
  OOO/блоков.
* Свои брони выделены (рамка); клик по своей — полная карточка, по чужой — карточка уровня «с
  фамилиями».

## 7. Тесты

* «Свой» за всё время: строка покрытия год назад — свой; будущая — свой; без строк — 403;
  подменный батлер после окончания подмены — свой; предварительная бронь — своя, с пометкой.
* Профиль своего гостя без `mine_guest_edit` — только чтение; с правом — правка разрешённых полей;
  запертые поля брони — 403; бронь выехавшего — правка разрешённых полей.
* Явный список гостей другого батлера сильнее строки «вся бронь» (как сейчас).
* `stays.view` у батлера: шахматка с фамилиями, без телефонов чужих гостей; запись — 403.
* Открытие профиля не создаёт записи аудита; изменение — создаёт.
* Бюджет запросов «Мои гости» и «Все мои гости» — не зависит от длины истории.
* Миграция прав: у ролей с `stays.edit_mine` — оба новых права.
* jsdom: «Сегодня», «Мой месяц» ◀ ▶, поиск в «Все мои гости», правка профиля.

## 8. Ответы владельца на открытые вопросы (27.10.2026)

1. **Предварительные брони в «Мои гости»** — видны, с пометкой (бледная полоса).
2. **Аудит открытий полного профиля** — не писать.
3. **Подменный батлер** — гости остаются «своими» навсегда: была строка покрытия → свой.
