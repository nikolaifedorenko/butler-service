# Доступность общих диалогов

> Навыки Superpowers для выполнения: test-driven-development, executing-plans, verification-before-completion.

**Цель.** Исправить клавиатурный сценарий карточки брони и других окон общего компонента.

**Архитектура.** Модалка, боковое окно и палитра используют существующий стек. Синхронизация слоёв обновляет доступность фона перед восстановлением фокуса. Публичные сигнатуры открытия окон сохраняются.

**Стек.** JavaScript ES modules, lit-html, Playwright Chromium, axe.

**Спецификация.** [Согласованный аудит, пункт 1](../specs/2026-11-26-ui-ux-audit-design.md).
