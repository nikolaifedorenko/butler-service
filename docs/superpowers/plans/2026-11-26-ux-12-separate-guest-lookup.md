# Отдельный поиск гостя из шахматки

**Спецификация.** [Согласованный аудит, пункт 12](../specs/2026-11-26-ui-ux-audit-design.md).

- [ ] Зафиксировать в Chromium, что фильтр текущего вида и отдельный поиск имеют разные имена и точки входа. Проверить сохранение периода, текста фильтра, выбранной группы и точки возврата после карточки.
- [ ] Проверить отсутствие поиска у роли «Занятость», область поиска своих гостей и запоздалые результаты от закрытого окна.
- [ ] Использовать диалог «Найти гостя», существующий API и карточку гостя. Состояние запроса привязать к одному открытому окну. Состояния загрузки, ошибки и пустого результата взять из общего компонента.
- [ ] Уточнить название фильтра текущего вида, сохранить его серверные параметры. На телефоне действие отдельного поиска доступно из шапки шахматки.
- [ ] Обновить руководство и сценарии карточки, прогнать регрессии доступа и клавиатуры. Выпустить самостоятельный PR.
