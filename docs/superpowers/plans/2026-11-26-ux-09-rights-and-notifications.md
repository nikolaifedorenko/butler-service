# Права по разделам и понятные состояния доставки

**Спецификация.** [Согласованный аудит, пункт 9](../specs/2026-11-26-ui-ux-audit-design.md).

- [ ] Проверить краткий итог по каждому разделу в ролях, раскрытие с клавиатуры, доступные подписи полей и сохранение настроенных прав среди закрытых групп.
- [ ] В браузере проверить разницу между сценарием, настройкой каналов и тестовой отправкой. Для проверки отправки подменить ответ сервера и не связываться с реальным каналом.
- [ ] Переиспользовать группировку по разделам каталога прав. Порядок применения прав и формат запроса оставить прежними.
- [ ] Показать состояние сценария независимо от конфигурации каналов. Различать принятый запрос на отправку и доставку. Обновить руководство, запустить регрессии администрации, открыть самостоятельный PR.
