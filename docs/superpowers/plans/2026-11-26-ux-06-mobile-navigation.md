# Настраиваемые быстрые разделы и прямое открытие брони

**Цель.** На телефоне оставить фиксированные «Сегодня» и «Разделы», добавить до трёх выбираемых вкладок и открывать конкретную бронь из «Сегодня».

**Спецификация.** [Согласованный аудит, пункт 6](../specs/2026-11-26-ui-ux-audit-design.md).

- [ ] Playwright: начальный набор для двух ролей, открытие полного каталога, настройка, сохранение после перезагрузки, отсутствие запрещённых разделов и сохранение активного состояния. Проверить, что две учётные записи в одном браузере получают свои настройки.
- [ ] Playwright: выбрать гостя из «Сегодня», проверить номер открытой брони, закрыть и убедиться в возврате фокуса к той же карточке. Проверить, что запоздавший ответ после перехода из «Сегодня» не открывает окно.
- [ ] Запустить тесты до реализации. Реализовать наборы в существующем каркасе `app.js`. Настройку сохранить локально для конкретной учётной записи, по принятому в приложении подходу к пользовательским предпочтениям. Доступные пункты ограничивает меню текущей роли.
- [ ] В `today.js` использовать существующую карточку брони и её механизм восстановления фокуса. Ссылка «Все мои гости» остаётся переходом в список.
- [ ] Сверить мобильный интерфейс, клавиатуру, права, документацию и текущую версию статики. Выпустить отдельный PR по порядку.
