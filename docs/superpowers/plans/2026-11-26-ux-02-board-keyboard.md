# Клавиатурная навигация по шахматке

**Цель.** Открывать бронь из месячной сетки клавиатурой за одну остановку Tab. Критерии определены пунктом 2 общего плана аудита.

**Архитектура.** Высветить уже существующие интерактивные полосы, сохранив обработку указателем и ограничения видимости. Выбранная полоса хранит единственный `tabindex="0"` в сетке. При отсутствии открываемых полос фокус остаётся доступен самой области прокрутки.

- [ ] Написать Playwright-сценарий для роли с просмотром гостей. Tab входит в сетку, правые и левые стрелки выбирают брони той же строки по началу, верхние и нижние — ближайшую по дате в следующей или предыдущей строке с бронями. Enter открывает именованный диалог и Escape возвращает фокус на ту же полосу. Следующий Tab покидает сетку.
- [ ] Проверить, что ограниченная роль видит занятость и не получает кнопок открытия гостевой брони, а в пустом состоянии сетка доступна для прокрутки.
- [ ] Проверить видимый фокус и заголовок объекта после горизонтального перемещения. Учитывать закреплённые области при прокрутке и не менять состав панели инструментов в этом PR.
- [ ] Запустить сценарии до изменения, затем реализовать управление в модуле шахматки и сфокусированное состояние в CSS.
- [ ] Прогнать новые проверки и смежные тесты шахматки, диалогов, доступности и мобильного экрана.
