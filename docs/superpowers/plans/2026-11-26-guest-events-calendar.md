# Календарь событий гостей

> Прототип задаёт месяц, дату и повестку. Superpowers TDD требует увидеть, как новый тест падает, затем проверить результат на API и в браузере.

**Цель.** Дать сотруднику обзор дней рождения, годовщин и особых дат, включая гостей без текущей брони, в пределах его прав.

**Архитектура.** Сервер выдаёт один месяц через `GET /api/stays/guest-events` и применяет права до подсчёта и фильтрации. Клиент использует действующие меню, календарную навигацию и карточку гостя.

- [x] Покрыть выдачу событий, доступ к участникам и статус размещения, годовые даты и независимость прав от состояния брони.
- [x] Покрыть фильтрацию несколькими VIP-кодами и совпадение всех критериев на одном человеке.
- [x] Проверить в Chromium навигацию по датам, независимые отметки выбранной даты и «сегодня», компактные фильтры, мобильную повестку, доступность обеих тем и карточек, скрытие раздела у роли загрузки.
- [x] Сверить документацию и OpenAPI, проверить линтеры и выполнить сценарии регрессии.
