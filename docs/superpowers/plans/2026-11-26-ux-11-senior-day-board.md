# Быстрое табло дня для старшего батлера на телефоне

**Спецификация.** [Согласованный аудит, пункт 11](../specs/2026-11-26-ui-ux-audit-design.md).

- [ ] В Chromium зафиксировать отсутствие текущего перехода. Добавить сценарии для старшего батлера на телефоне, входа с компьютера, сотрудника и пользователя без доступа к шахматке.
- [ ] Переиспользовать обычное «Табло дня». Открывать текущую дату объекта и список заездов. Сохранить вкладку и дату обычного входа, если пользователь пришёл через быстрый переход.
- [ ] Сравнить маршруты на трёх фиксированных примерах. Найти ближайший заезд, ближайший выезд и гостя без батлера. Записать число нажатий от «Сегодня» и проверяемый результат.
- [ ] Проверить фокус и доступность на телефоне, описать поведение в руководстве и выпустить отдельный PR.

## Сравнение маршрутов

На мобильном стенде обе ветки проверяет сценарий `e2e/senior-day-board.spec.mjs`.
Отсчёт начинается на «Сегодня» с обычной вкладкой шахматки «Объекты». В обычном
маршруте «Шахматка» закреплена в нижней панели старшего батлера.

| Задача | Обычный маршрут | Через «Табло дня» | Проверяемый результат |
|---|---:|---:|---|
| Найти ближайший заезд | 2 нажатия | 1 нажатие | Первая бронь в 08:30 |
| Найти ближайший выезд | 3 нажатия | 2 нажатия | Выезд в 09:00 |
| Найти гостя без батлера | 3 нажатия | 2 нажатия | Бронь с подписью «не назначено» |
