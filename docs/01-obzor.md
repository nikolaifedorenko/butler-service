# 1. Обзор

## 1.1 Что это

«Батлер Сервис» — рабочее место батлерской службы отеля. Система выросла из учёта рабочего
времени и охватывает:

| Область | Что делает |
|---|---|
| Учёт времени | График, Факт, Табель и Управленческий табель; отметки «пришёл / ушёл» с телефона; банк часов; коды переработок ДЯ / ДН / ДЯ2 / ДН2; закрытие и пересчёт периодов; выгрузки в Excel и PDF |
| Шахматка | кто из гостей где и когда живёт и какой батлер их ведёт: фонд объектов, брони, блоки, недоступность (OOO), размещение, табло дня, нагрузка батлеров, «Мои гости» |
| Ночной отчёт | обход зон и объектов по чек-листам, замечания службам, фото, закрытие смены |
| Электрокары | парк, места стоянки, выдача и возврат, замечания |
| Документы | заявления сотрудников по шаблонам .docx, печать, PDF |
| Уведомления | Telegram и почта, очередь исходящих сообщений |
| Настройки и права | справочники и правила расчёта версиями с даты, роли и группы, журнал аудита |

Отель один. Второй возможен в будущем — правила, которые это не закрывают, описаны в
[документе 2](02-arhitektura.md), раздел 2.2.

Планы владельца (порядок): импорт броней из выгрузки Fidelio (CSV), прямое подключение к базе
Fidelio, статусы уборки, работа с гостями (CRM), расчёты с гостями. Эти модули заранее не
создаются; точки подключения описаны в ADR-0013, разделы 1 и 6.

## 1.2 Роли и демо-доступы

Роли — данные (ADR-0011): четыре встроенные (`admin`, `manager`, `supervisor`, `employee`) и
свои; права каждой роли настраиваются в «Настройки → Права доступа», поверх ролей работают
группы и индивидуальные гранты. Подробно — [документ 5](05-bezopasnost.md), раздел 5.4.

Демо-база (`DEMO_SEED=1`) создаёт пользователей с паролем `demo1234`:

| Логин | Роль | Что видит |
|---|---|---|
| `admin` | Администратор | всё, справочники, права |
| `smirnov` | Менеджер | все вкладки учёта, сотрудники |
| `gromova` | Старший батлер | как менеджер, без корректировок банка |
| `ivanov`, `petrov`, `volkov` | Сотрудник | свои отметки, Факт, График на просмотр, «Мои гости» |
| `rukovod` | Руководство | «Шахматка» целиком, без правки |
| `sluzhba` | Загрузка без гостей | «Шахматка»: занятость без данных гостей |

В боевой базе демо-учёток нет: первый администратор создаётся из `ADMIN_PASSWORD`.
