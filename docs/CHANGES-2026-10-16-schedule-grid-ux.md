# Изменения 16.10.2026 — сетка «Слой 1 · План / График»: содержимое ячеек, печать, сброс месяца

Батч из восьми правок владельца (16.10.2026) для слоя 1: ячейка показывает только
смену (без кода Табеля), цвета — из словаря «Смены и отсутствия», отлучки видны
разрезом по строкам, «выходной за часы» — плашкой на весь день; печать повторяет
экран и разделяет блоки; «Сбросить месяц» больше не трогает Табель.

## 1. Кнопка «Отпросить (выходной за часы)» → «Выходной за часы»

Переименованы кнопка панели и заголовок модалки назначения на период; смысл
прежний — только вид «за счёт часов» (Q4), Табель остаётся явкой.

## 2. «Обнулить месяц» → «Сбросить месяц»: только ручные смены Графика

Прежняя кнопка удаляла строки Табеля месяца (clear-month). Теперь
`POST /api/schedule/reset-month` убирает РУЧНЫЕ смены месяца и перегенерирует
График из Табеля:

* Табель НЕ трогается — он сбрасывается из «Слой 0 · Табель» (своя кнопка);
* согласованные отсутствия (отлучки) сохраняются — это документированные записи
  с заявлениями, удаляются в ячейке дня;
* закрытые периоды не трогаются; действие аудируется (`schedule_reset_month`).

Эндпоинт `clear-month` сохранён (используется тестами и для «полной очистки»).

## 3. Ячейка показывает только смену, без кода Табеля

Было «Я 12 08:00–20:00» — стало «08:00–20:00». Код Табеля живёт в слое 0 и в
подсказке ячейки. Дни без смены (В, ОТ, ДО…) по-прежнему показывают код.
Колонка дня расширена 56→60px — интервал помещается в одну строку.

## 4. Цвет ячейки — из словаря «Смены и отсутствия»

Смена матчится по времени окна со словарной сменой (DAY12 08:00–20:00 → её
зелёный, NIGHT12 → её синий, СУТКИ → фиолетовый…), код отсутствия — по `tzh_code`
словаря (ОТ → цвет «Отпуска», Б → цвет «Больничного»…). Если совпадения нет
(ручная смена вне словаря) — запасной вариант, прежний цвет кода Табеля.
Легенда под сеткой пересобрана: показывает реально использованные в месяце
смены/коды в их цветах.

## 5. Отлучки видны разрезом: отрезки смены по строкам

Смена 08:00–20:00 с отсутствиями 12:00–14:00 и 16:00–17:00 показывается как:

```
08:00–12:00
14:00–16:00
17:00–20:00
```

`GET /api/schedule` отдаёт на ячейку `segments` — видимые отрезки (смена минус
интервалы отсутствий). Арифметика — на сервере, по реальным UTC-моментам записей,
поэтому смена через полночь режется без особых случаев. Разрез по-прежнему
логический (v7/R17): записи смен не меняются, на часы не влияет.

## 6. Печать = экран: те же размеры ячеек

`printGrid` переписан: та же геометрия (имя 232px, день 60px, итого 80px,
строка 52px, те же шрифты и содержимое ячеек). Физически 1:1 месяц на A4 не
помещается (31 день × ~15 мм > 277 мм полезной ширины), поэтому:

* дни режутся на страницы по ≤16 — колонка ФИО и заголовки блоков повторяются
  на каждой странице;
* лист пропорционально масштабируется под ширину страницы ОДНИМ коэффициентом
  (`zoom ≈ 0.88`) — форма и пропорции ячеек остаются экранными.

## 7. Печать разделяет блоки; порядок: старшие → алфавит

Блоки (Смена 1, Смена 2, Пятидневка, Другие смены) на печати разделены
заголовками-строками, как на экране. Порядок сотрудников внутри блока задаёт
СЕРВЕР (`_visible_employees`: блок → «старшие» (должность содержит «старш») →
алфавит) — поэтому он одинаков на экране, в печати, PDF и Excel.

## 8. Отсутствие на всю смену — плашка «Выходной за часы» на весь день

**Архитектура**: признак «отсутствие покрывает всё рабочее окно дня» (EX-29)
уже считался сервером для выбора заявления (`_covers_whole_day`). Правило
вынесено в чистую функцию `_covers_window(Settings, строка Табеля, день, начало,
конец)` — ЕДИНСТВЕННЫЙ источник: его используют и заявления (`absence-period`),
и сетка (`GET /api/schedule` отдаёт `whole_shift` на каждой записи отсутствия).
Второй копии правила на фронтенде нет (дух антипаттерна 12.23): экран, печать
и PDF лишь рисуют плашку по готовому флагу. Для роли сотрудника `whole_shift`
сохранён в урезанном payload (плановые данные, без id и примечаний).

Ячейка с плашкой не показывает отрезки (смена закрыта целиком); цвет плашки —
цвет вида отсутствия из словаря. В PDF/DOCX — та же плашка («Выходной за часы»).
